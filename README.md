# Phishing Awareness Guide
A practical guide and checklist to help staff spot, report and respond to phishing emails.
## Purpose
Phishing is one of the most common ways attackers steal credentials and deliver malware. This project gives non-technical staff clear, simple guidance to recognize suspicious messages and report them quickly.
## Audience
-General employees and students
-IT help desk staff
-Junior cybersecurity analysts
## Contents
- "docs/" - phishing overview, red flags checklist and reporting procedure (coming soon)
- "templates/"- phishing incident report template (coming soon)
  ## How to use
  1. Read the overview to understand commo0n phishing types.
  2. Use the red flags checklist whenever you receive a suspicious message.
  3. If in doubt, do not click. Report using the reporting procedure.
